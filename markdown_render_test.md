# Приоритет 1

## 1. Переносы строк

Обычный перенос строки  
должен оставаться soft break.

Обычный перенос строки
не должен автоматически превращаться в принудительный `<br>`.

Жёсткий перенос с двумя пробелами  
следующая строка должна начинаться с новой строки.

Жёсткий перенос через обратный слеш\
следующая строка также должна начинаться с новой строки.

Текст в одном абзаце
с несколькими
обычными переносами
для проверки поведения soft break.

## 5. Fenced code blocks

### Блок без указания языка

```

```

Первая строка `hello` является кодом, а не названием языка.

### Блок с указанием языка

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, Markdown!" << '\n';
    return 0;

## 6. Emphasis и strong emphasis

*Курсив через звёздочки*

_Курсив через подчёркивания_

**Жирный текст через звёздочки**

__Жирный текст через подчёркивания__

***Жирный курсив***

___Жирный курсив через подчёркивания___

**Жирный текст с _курсивом_ внутри**

__Жирный текст с *курсивом* внутри__

*Курсив с **жирным** фрагментом внутри*

Проверка подчёркиваний внутри слова:

some_variable_name

file_name_example

Проверка знаков пунктуации:

(*курсив в скобках*)

**жирный текст!**

_курсивный текст._
